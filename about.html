专业技能

CONFIG_MM=y内存管理：Buddy、Slab/Slub、THP、NUMA、页回收与水位 // 两个上游补丁的主战场
CONFIG_SCHED=yCFS / EEVDF 调度器：抢占、负载均衡、延迟分析
CONFIG_BPF=yBPF 子系统原理：verifier、map、ringbuf、kprobe/tracepoint 埋点
CONFIG_VFS=yVFS 与文件系统、中断 / 软中断、网络协议栈
CONFIG_EBPF_TOOL=m性能观测与故障诊断：eBPF、perf、ftrace、systemtap // libbpf / BCC 双修
CONFIG_CRASH=ycrash / vmcore 分析：独立定位 Panic、死锁、OOM、内存泄漏、调度抖动等疑难问题
CONFIG_TUNING=y性能调优：sysctl 调优、CPU 调度优化、缓存、上下文切换优化
CONFIG_LANG=y开发语言与工具链：熟练 C / C++，掌握 Shell、Python；GDB、Git、Makefile、CM
CONFIG_NETLINK=m内核网络编程：Netlink（INET_DIAG）、TCP/IP 诊断、TC / Netem 故障注入

# End of config. 没有 =d 选项——要么用，要么没有。
